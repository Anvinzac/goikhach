## Detailed Inspection Criteria

### Professional Appearance (Requirement 6.4)
Check for:
- Clean, polished visual design
- Appropriate spacing and alignment
- No visual glitches or artifacts
- Colors work harmoniously together
- Theme feels cohesive and intentional

### Text Readability (Requirements 7.4, 7.5)
Check for:
- **Body text** (primaryLight): Clearly readable, sufficient contrast
- **Labels/secondary text** (primaryDim): Readable, not too faint
- **Queue numbers**: Prominent and legible with gradient effect
- **All text elements**: No strain required to read

### Gradient Rendering (Requirement 7.6)
Check for:
- Smooth color transitions (no visible banding)
- Gradients render correctly in browser
- No harsh edges or abrupt color changes
- Watercolor themes show fluid, artistic blending
- Drop-shadow effects render properly on queue numbers

### Visual Distinctiveness (Requirement 6.4)
Check for:
- Each theme looks clearly different from others
- Themes are immediately recognizable
- No themes appear too similar to each other
- Each theme has unique character and identity

## Testing Instructions

### How to Access Themes
1. Start the development server: `npm run dev`
2. Open the application in your browser
3. Navigate to the waiting card display page
4. Look for the theme selector (usually in settings or preferences)
5. Select each theme one by one

### How to Test Card Layouts
For each theme:
1. Select the theme from the theme selector
2. Navigate through all 6 card layout options:
   - ClassicCard
   - TicketStrip
   - RadialHub
   - SplitScreen
   - TimelineJourney
   - CardStack
3. For each layout, check:
   - Professional appearance
   - Text readability
   - Gradient rendering
4. Mark the checklist items above

### What to Look For
- **Text Contrast**: Can you easily read all text without straining?
- **Gradient Quality**: Do gradients look smooth or do you see color bands?
- **Visual Polish**: Does the theme look professional and well-designed?
- **Consistency**: Does the theme work well across all layouts?

### Taking Screenshots (Optional)
If you find issues, take screenshots to document them:
1. Use browser dev tools or screenshot tool
2. Save with descriptive names: `theme-name_layout-name_issue.png`
3. Attach to issue reports
